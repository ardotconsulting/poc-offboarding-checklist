# poc-offboarding-checklist

Interactive offboarding checklist proof of concept for
[Automating Employee Offboarding with Open Source Tools](https://www.ardotconsulting.com/2026/11/22/automating-employee-offboarding-with-open-source-tools/).

A single-container Flask web app that presents a configurable employee
offboarding checklist (revoke access, recover hardware, transfer data, process
paperwork, archive accounts, update directories, notify stakeholders). Visitors
can check off items, see a live progress bar, and view an audit log of all
actions taken.

**Live demo:** https://offboarding-checklist.poc.ardotconsulting.com
